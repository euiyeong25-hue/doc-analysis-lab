# 같은 문서, 두 분석가 — 문서분석 실습 사이트

질적연구방법론 8장(문서분석) 발표용 실습 사이트. 학생은 **로그인 없이** 링크·QR로 들어와서 같은 칼럼을 읽고 분석합니다. 사람이 먼저 읽고, 사이트 안의 Claude가 같은 과제를 하고, 둘을 나란히 비교한 뒤, 반 전체 답을 보드에 모읍니다.

| 화면 | 주소 | 누가 |
|---|---|---|
| 학생 | `/` | 휴대폰·노트북. 이름(별명)만 적고 입장 |
| 보드 | `/board` | 프로젝터. 대기 단계에서 큰 QR, 단계마다 진행 막대와 반 전체 결과 |
| 발표자 | `/admin` | 발표자(ADMIN_CODE). 단계 넘기기, 참여자와 사람별 답, 본문 올리기, 설정, 내려받기 |

## 수업 흐름 (40분)

도입 2분 30초 → **실습 1** 11분(① 혼자 읽기 4 · ② AI에게 3.5 · ③ 비교 3.5) → **설명** 7분 → **재실습** 14분 30초(⓪ 출처·자료 2 · ① 다시 코딩 5 · ② AI에게 3 · ③ 비교 4.5) → **정리** 4분 → 여유 1분

- 발표자 화면에서 단계를 넘기면 학생 화면과 보드가 3초 안에 같이 넘어갑니다. 남은 시간도 같이 셉니다.
- 학생은 지난 단계를 다시 열어 고칠 수 있고, ‘지금 단계로’를 누르면 돌아옵니다. 글을 쓰는 중이면 화면을 억지로 넘기지 않습니다.
- 답은 칸마다 자동 저장됩니다. 화면을 닫았다가 다시 열어도 이어서 할 수 있습니다.
- 실습 1은 문단 단위(중요한 문단 1~2개 + 한 문장), 재실습은 문장 단위로 다시 코딩합니다(`[문단-문장]` 번호에 코드).
- AI는 ‘AI에게’와 ‘비교’ 단계에서만 돌아갑니다. 재실습에서는 학생이 찾은 출처·추가 자료를 같이 줘 볼 수 있습니다.

## 참여자 확인

`/admin` → **참여자** 칸에 들어온 사람이 모두 뜹니다(4초마다 새로 고침).

- 단계별로 다 한 사람 수가 막대로, 사람마다 8칸 점으로 보입니다.
- 이름을 누르면 그 사람의 답(1차 · AI · 비교 · 출처 · 다시 코딩 · AI · 비교)이 펼쳐집니다.
- 발표자도 휴대폰이나 다른 탭으로 `/`에 들어가 이름을 적으면 참여자로 같이 뜹니다.
- 보드에는 기본으로 이름 없이 답만 모입니다(설정에서 ‘보드에 이름 보이기’).

## 배포 (처음 한 번)

1. **Vercel:** https://vercel.com 에 GitHub 계정으로 로그인 → Add New → Project → 이 저장소 Import → Deploy.
2. **저장소(무료):** 프로젝트 → **Storage** → **Upstash for Redis**(Free) 만들기 → 이 프로젝트에 Connect. 환경변수 이름 앞부분은 기본값 그대로.
3. **Claude API 키:** https://platform.claude.com 에서 결제 수단을 등록하고, https://platform.claude.com/settings/keys 에서 키를 만듭니다.
4. **환경변수:** 프로젝트 → Settings → Environment Variables

   | 이름 | 값 |
   |---|---|
   | `ANTHROPIC_API_KEY` | 3에서 만든 키 |
   | `ADMIN_CODE` | 발표자 비밀번호 (아무 문자열) |
   | `MODEL` (선택) | 기본 `claude-sonnet-5-5`. 더 싸고 빠르게는 `claude-haiku-5-5` |
   | `MAX_CALLS` (선택) | 수업 전체 AI 호출 상한, 기본 300 |

5. **다시 배포:** Deployments → 최신 배포 → **Redeploy**. 환경변수는 다시 배포해야 반영됩니다.
6. **확인:** `/admin`에 코드를 넣고 들어가 맨 위가 **AI 연결됨 · 저장소 연결됨**인지 봅니다.

## 수업 전

1. `/admin` → **본문**에 칼럼을 붙여 넣고 저장합니다. ‘번호 붙은 모양 미리 보기’로 문단·소제목이 제대로 나뉘었는지 봅니다. (사이트에는 원문이 들어 있지 않습니다.)
2. 휴대폰 두어 대로 `/`에 들어가 한 바퀴 돌려 보고, `/board`에 모이는지 확인합니다.
3. 수업 직전 `/admin` → **모두 지우기**(두 번 누름). 본문과 설정은 남고 참여자·답·AI 사용량만 지워집니다. 열려 있던 학생 화면은 이름 입력으로 돌아갑니다.

## 비용과 안전장치

- **비용:** Sonnet 5.5 기준 100만 토큰당 입력 $2, 출력 $10. 본문 부분은 학생마다 같아서 캐시해 다시 씁니다(캐시 읽기는 입력값의 10%). 25명이 단계마다 2번씩 돌려도 수업 한 번에 1~2달러 안팎입니다. `/admin` 맨 위에 호출 수와 예상 비용이 나옵니다.
- **키 보호:** API 키는 Vercel 서버에만 있고 브라우저로 나가지 않습니다.
- **호출 제한:** 학생 1명당 단계마다 N번(발표자 설정, 기본 2번), 수업 전체로는 `MAX_CALLS`번까지.
- **처음 만든 API 계정**은 사용 한도가 낮게 시작할 수 있습니다. 수업 전에 Console의 Rate limits 화면(https://platform.claude.com/usage/limits)을 확인하고, 리허설로 몇 번 돌려 두면 좋습니다. 붐빌 때는 서버가 두 번까지 다시 시도하고, 학생 화면에는 ‘한 번 더 눌러 주세요’가 뜹니다.
- **기록:** 모든 AI 답은 모델 · 실행 시각 · 보낸 질문과 함께 저장됩니다. AI의 분석도 하나의 문서이기 때문입니다.
- **수업 후:** `/admin` → 전체 내려받기(JSON) 또는 사람별 답(CSV) → 모두 지우기.

## 로컬 테스트

```bash
npm install
ADMIN_CODE=test npm run dev   # http://localhost:3000
```

API 키나 DB 없이도 **테스트 모드**로 전체 흐름이 돌아갑니다. AI 답 자리에는 ‘[테스트 모드]’ 문구가 나옵니다.

## 구조

```
api/      서버리스 함수: state(단계·본문) join me submit(자동 저장) analyze(AI) board(반 전체) admin(발표자)
lib/      store(Upstash Redis / 메모리) · ai(Claude 호출, 캐시) · agg(반 전체 집계) · util(설정)
public/   index.html(학생) board.html(보드) admin.html(발표자)
  assets/ text.js(본문 번호·문장 나누기·AI 질문, 서버와 함께 씀) charts.js common.js style.css
dev/      로컬 테스트 서버 (배포에는 쓰이지 않음)
```
