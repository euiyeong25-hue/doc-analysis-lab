# 같은 문서, 두 분석가 — 문서분석 실습 사이트

질적연구방법론 8장(문서분석) 발표용 실습 사이트. 학생은 **로그인 없이** 링크·QR로 들어와서 같은 칼럼을 읽고 분석합니다.

- 사람이 먼저 분석하고
- 사이트 안의 Claude가 같은 발췌문을 분석하고
- 둘을 나란히 비교하고
- 반 전체의 답을 보드에 모읍니다.

| 화면 | 주소 | 누가 |
|---|---|---|
| 학생 | `/` | 휴대폰·노트북 |
| 보드 | `/board` | 프로젝터 (대기 단계에서 큰 QR) |
| 발표자 | `/admin` | 발표자 (ADMIN_CODE로 입장) |

**수업 흐름:** 대기 → 실습 1(사람 → AI → 비교) → 설명 → 재실습(사람 → AI → 비교) → 정리.
발표자 화면에서 단계 버튼을 누르면 학생 화면과 보드가 2~3초 안에 같이 넘어갑니다.

---

## 배포 (처음 한 번, 15분쯤)

1. **Vercel 가입:** https://vercel.com 에 GitHub 계정으로 로그인합니다.
2. **프로젝트 만들기:** Add New → Project → 이 저장소(`doc-analysis-lab`)를 Import → 설정은 그대로 두고 Deploy.
3. **저장소(무료) 연결:**
   1. 프로젝트 → **Storage** → **Upstash for Redis**(Free) 만들기
   2. 이 프로젝트에 Connect. 환경변수 이름 앞부분은 기본값 그대로 둡니다.
4. **Claude API 키 만들기:**
   1. https://platform.claude.com 에 가입하고 결제 수단을 등록합니다.
   2. https://platform.claude.com/settings/keys 에서 새 키를 만들어 복사합니다.
5. **환경변수 넣기:** 프로젝트 → Settings → Environment Variables
   | 이름 | 값 |
   |---|---|
   | `ANTHROPIC_API_KEY` | 4번에서 복사한 키 |
   | `ADMIN_CODE` | 발표자 비밀번호 (아무 문자열) |
   | `MODEL` (선택) | 기본 `claude-sonnet-5-5`, 더 싸고 빠르게는 `claude-haiku-5-5` |
   | `MAX_CALLS` (선택) | 수업 전체 AI 호출 상한, 기본 300 |
6. **다시 배포:** Deployments → 최신 배포 → **Redeploy**. 환경변수는 다시 배포해야 반영됩니다.
7. **확인:** `https://<프로젝트>.vercel.app/admin` 에 들어가 코드를 입력하고, 위쪽 상태가 **AI 연결됨 · 저장소 연결됨** 인지 봅니다.

## 수업 전 리허설

1. `/admin` 에서 발췌문을 붙여넣고 저장합니다. 사이트에는 원문이 들어 있지 않으니, 원문에서 직접 고른 4~5줄을 넣으세요.
2. 휴대폰으로 `/` 에 들어가 단계를 한 바퀴 돌려 보고, `/board` 에 모이는지 확인합니다.
3. 끝나면 `/admin` → **모두 지우기**.

## 비용과 안전장치

- **비용:** Sonnet 5.5 기준 100만 토큰당 입력 $2, 출력 $10입니다. 분석 한 번에 1~2센트쯤이라, 20명이 2단계 × 최대 2번 돌려도 1~2달러 안팎입니다. `/admin` 현황에 호출 수·토큰·예상 비용이 나옵니다.
- **키 보호:** API 키는 Vercel 서버에만 있고 브라우저로 나가지 않습니다.
- **호출 제한:** AI는 AI 단계와 비교 단계에서만 돌아갑니다. 학생 1명당 단계마다 최대 N번(발표자 설정), 수업 전체로는 `MAX_CALLS`번까지입니다.
- **기록:** 모든 AI 답은 모델·실행 시각·보낸 프롬프트와 함께 저장됩니다. AI의 분석도 하나의 문서이기 때문입니다.
- **수업 후:** `/admin` → 전체 내려받기(JSON) → 모두 지우기. 필요 없으면 Upstash DB도 지우면 됩니다.

## 로컬 테스트

```bash
npm install
ADMIN_CODE=test npm run dev   # http://localhost:3000
```

API 키나 DB 없이도 **테스트 모드**로 전체 흐름이 돌아갑니다. AI 답 자리에는 '[테스트 모드]' 문구가 나옵니다.

## 구조

```
api/      Vercel 서버리스 함수 (state, join, me, submit, analyze, board, admin)
lib/      저장소(Upstash Redis / 메모리), Claude 호출, 공통 설정
public/   학생·보드·발표자 화면 (정적 HTML + JS)
dev/      로컬 테스트 서버 (배포에는 쓰이지 않음)
```
